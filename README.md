# Calculadora-simples usando HTML, CSS e JavaScript!

    <summary>Programa necessario e Passo a Passo ✍️</summary>
<p>"<mark>VisualCode</mark>"</p>
<li><strong>Passo 1:</strong> crie uma pasta em um local de sua escolha(exemplo: Area de Trabalho);</li>
<li><strong>Passo 2:</strong> Abra essa pasta com o VSCODE;</li>
<li><strong>Passo 3:</strong> Crie um arquivo nessa pasta e nomeie como preferir(exemplo: Calculadora);</li>
<li><strong>Passo 4:</strong> copie o codigo do Repositorio "Calculadora.html" no seu VSCODE(nomeie com o nome que você preferir);</li>
<li><strong>Passo 5:</strong> abra esse arquivo com o navegador e aproveite a sua calculadora que você criou! 😁</li>
